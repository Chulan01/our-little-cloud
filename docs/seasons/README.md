# Сезонная система оформления

Сайт автоматически меняет цветовые акценты в зависимости от сезона, сохраняя фирменную розовую палитру как основу.

## Сезоны

### Весна (март–май)
**Файл:** `spring-day.png`, `spring-night.png`

Мягкие зелёные акценты. Aurora слева имеет зеленоватый оттенок, точечный узор — на зелёной основе. Плавающие сердечки остаются розовыми. Создаёт ощущение свежести и возрождения.

### Лето (июнь–август)
**Файл:** `summer-day.png`

Тёплое золото и персик. Aurora в центре и справа светит тёплыми оттенками — персиковые и золотые блики. Узор и сердечки теплеют вместе. Сейчас **текущий сезон** (июль).

### Осень (сентябрь–ноябрь)
**Файл:** `autumn-day.png`

Терракота и оранжевый. Aurora приобретает тёплый оранжево-коричневый оттенок, узор — более насыщенный оранжевый. Создаёт уютное, тёплое ощущение.

### Зима (декабрь–февраль)
**Файл:** `winter-day.png`, `winter-night.png`

Холодная сирень и фиолет. Aurora имеет сиреневый оттенок, узор — фиолетовый. В ночной теме этот сезон смотрится особенно красиво — сиревый свет на глубокой сливовой основе.

## Реализация

- **`src/lib/season.ts`** — функции `getCurrentSeason()`, `getSeason(month)` для определения сезона по месяцу
- **`src/app/layout.tsx`** — серверно устанавливает `data-season` атрибут на `<html>`
- **`src/app/globals.css`** — CSS-переменные `--season-glow-warm`, `--season-glow-cool`, `--season-pattern`, `--season-heart`, переопределяемые для каждого сезона
- **`src/components/ambience/FloatingAmbience.tsx`** — плавающие сердечки используют `var(--season-heart)`

## Тёмная тема

Ночная тема поддерживает все сезоны. Aurora становится ярче и насыщеннее для читаемости на тёмной основе (см. скриншоты `spring-night.png`, `winter-night.png`).

## Добавление нового сезона

1. Добавьте запись в `SEASON_COLORS` в `src/lib/season.ts`
2. Добавьте блок `:root[data-season="..."]` в `src/app/globals.css` с переопределениями переменных
3. Тестируйте через `document.documentElement.setAttribute('data-season', 'название')`
